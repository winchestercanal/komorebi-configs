## 📍 Localização do Arquivo

O arquivo `komorebi.json` deve ser colocado no seguinte diretório:

```
%USERPROFILE%
```

Ou seja:

```
C:\Users\SEU_USUÁRIO\
```

> [!TIP]
> `%USERPROFILE%` é uma variável de ambiente do Windows que aponta automaticamente para a pasta do seu usuário. Cole esse caminho direto na barra de endereços do Explorador de Arquivos para abri-la rapidamente.
